# Fuente de datos
El conjunto de datos proviene del trabajo de investigación <trabajo de tesis> [ ], en el cual se detalla el proceso experimental realizado con gránulos de kéfir de agua.

En el experimento, a una cantidad inicial de gránulos se le aplicó un pretratamiento de ultrasonido con una intensidad y un tiempo de exposición definidos. Posteriormente, los gránulos se mantuvieron bajo condiciones controladas de temperatura y presión durante un periodo de 175 horas, realizando mediciones de concentración cada 15 horas.

El dataset está compuesto por cinco series de tiempo, cada una conformada por 15 puntos equiespaciados. Cada serie representa el crecimiento de los gránulos asociado a un pretratamiento específico.
